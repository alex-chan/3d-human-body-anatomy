# Movement Lab 国际化

动作库及 50 个动作页提供简体中文、英语、西班牙语、法语、德语、葡萄牙语、日语、韩语。
中文使用原路径，其他语言使用 `/en/`、`/es/`、`/fr/`、`/de/`、`/pt/`、`/ja/`、`/ko/` 前缀，例如 `/en/exercises/bench/`。
页面顶部提供语言选择器，切换保留当前动作和查询参数。语言偏好保存在 `movement.locale`，重新进入根首页时恢复。显式带语言前缀的链接优先。搜索支持本地名称、肌肉、器械、英文名及中文名，并忽略拉丁字母重音。

## 内容维护

- `src/locales/ui.js`：导航、说明面板、播放控制及无障碍文案。
- `src/locales/terms.js`：动作名、肌肉名、器械与部位。
- `src/locales/guides.js`：按动作模式组织的多语言要领与准备姿势。中文保持原有逐动作说明。
- 上述数组依次为英语、西班牙语、法语、德语、葡萄牙语、日语、韩语。品牌字样保留英文。
- 新增动作时补全标题、动作模式和新增肌群/器械术语，运行 `npm run check:i18n`。
- 原人体图谱的知识资料、讲解及其原有界面仍为英语/印地语；入口有明确标注。此部分未宣称完成八语言知识翻译。

## 验证与上线

运行 `npm run check:i18n`、`npm run build`、`npm run check:seo`。
构建生成 416 个内容页和 8 个本地化错误页；每页包含对应语言的静态标题、说明、结构化数据和 `lang`。
设置真实的 `SITE_URL` 后，自动生成各语言 canonical、hreflang（含 x-default）和 sitemap。域名未定时仍保持原来的 noindex 配置，不使用虚构正式域名。
